How a run happens

This application cannot start containers: it holds no Docker socket by design. Pressing Queue Run writes a run spec to the spool. A host-side broker picks it up, re-validates it against its own registry, and executes it in a sandbox: 

python3 deploy/lab_broker.py --once     # drain the spool
python3 deploy/lab_broker.py --watch    # keep draining
